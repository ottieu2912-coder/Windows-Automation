Note: This was only created and tested on Windows. Its performance on other operating systems is unknown.

Step 1: "How many files would you like to make?"
Enter the number of files that you want to make(The input must be an integer)

Step 2: "Enter the location of the new file(s):"
Go to File Explorer(Find on Mac) and then right click on the folder that you want the files to be in. Then click "Copy as path". Replace every "/" with "//" or "\"

Repeated Loop:
Step 3: "Enter the file that you want to copy from"
Same as step 2

Step 4: "Name these files"
Type in the name

Step 5: "What kind of file would you like to make?"
press 1 for Word, 2 for Excel, and 3 for Powerpoint

Step6: "How many files would you like to make?"
Enter an integer that is less than the number that you entered in step 1
